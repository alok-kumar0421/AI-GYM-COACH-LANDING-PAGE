# AI Gym Coach Landing Page

This repository contains the landing page for the AI Real-Time Gym Coach project.

The website provides an overview of the project, its features, technology stack, workflow, and live demo.

## Live Website

🌐 https://gymai.alokteh.in

## About The Project

AI Real-Time Gym Coach is a computer vision based fitness application that helps users track workouts, count repetitions, analyze exercise form, and monitor progress in real time.

This landing page was created to present the project in a clean and user-friendly way.
